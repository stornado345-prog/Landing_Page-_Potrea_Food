# 🍛 Poetra Food — Self-Order Restaurant Landing Page

**Poetra Food** is a modern landing page for a self-order restaurant system designed for restaurants, cafés, and UMKM businesses.

The concept focuses on providing a simple and convenient ordering experience through **Android tablets and self-service kiosks**.

## 🌐 Live Demo

**Poetra Food Landing Page**

## 📱 About Poetra Food

Poetra Food is a self-order restaurant application concept that allows customers to browse menus, select food and drinks, manage their cart, and place orders through a tablet or kiosk.

The system is designed to help restaurants and small businesses improve the ordering process and reduce manual ordering workload.

### Main Concept

```text
Customer
   ↓
Android Tablet / Self-Service Kiosk
   ↓
Browse Menu
   ↓
Select Food & Drinks
   ↓
Cart
   ↓
Order
   ↓
Restaurant Order Processing
```

## 🚀 Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/stornado345-prog/Landing_Page-_Potrea_Food.git
```

### 2. Enter the project directory

```bash
cd Landing_Page-_Potrea_Food
```

### 3. Install dependencies

```bash
npm install --legacy-peer-deps
```

### 4. Run the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## 📦 Production Build

To create a production build:

```bash
npm run build
```

The production files will be generated inside:

```text
dist/
```

To preview the production build locally:

```bash
npm run preview
```

## 🌍 Deployment

This project is deployed using **GitHub Actions and GitHub Pages**.

The deployment process is:

```text
Source Code
     ↓
GitHub Repository
     ↓
GitHub Actions
     ↓
Vite Production Build
     ↓
dist/
     ↓
GitHub Pages
     ↓
Live Website
```

Every update pushed to the `main` branch can trigger the deployment workflow.
